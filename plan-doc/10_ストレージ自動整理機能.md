# 📘 Cloudflare R2 + Workers + KV  
## **2年間アクセスがないオブジェクトを自動削除する仕組み（簡易ドキュメント）**

このドキュメントは、Cloudflare R2 に保存したオブジェクトについて  
**「最終アクセス日時を記録し、2年以上アクセスがないものを自動削除する」**  
ための最小構成を説明します。

---

# 1. 全体構成

```
ユーザー
   ↓（GET）
Workers（アクセスログを記録）
   ↓
R2（オブジェクト取得）

Workers Cron（毎日実行）
   ↓
KV.list() をページングしながら全キーをチェック
   ↓
2年以上アクセスなし → R2 から削除
```

---

# 2. 使用する Cloudflare サービス

| サービス | 用途 |
|---------|------|
| **R2** | オブジェクト保存（ファイル名＝内容ハッシュ） |
| **Workers** | アクセス時にログ記録／Cron で削除処理 |
| **KV** | オブジェクトの最終アクセス日時を保存 |

---

# 3. アクセス時に最終アクセス日時を記録する Worker

ユーザーがオブジェクトを読み込むたびに、  
**KV に「最終アクセス日時（UNIX時間）」を保存**します。

```javascript
export default {
  async fetch(request, env) {
    const url = new URL(request.url);
    const key = url.pathname.slice(1); // ハッシュ名そのまま

    // 最終アクセス日時を記録
    await env.ACCESS_LOG.put(key, Date.now().toString());

    // R2 からオブジェクト取得
    const object = await env.MY_BUCKET.get(key);
    if (!object) return new Response("Not found", { status: 404 });

    return new Response(object.body, {
      headers: { "Content-Type": object.httpMetadata?.contentType }
    });
  }
};
```

# 4. Cron Worker（毎日実行）  
## KV.list() をページングしながら全オブジェクトをチェック

KV.list() は最大 1,000件ずつ返すため、  
**cursor を使ってページングしながら全キーを処理**します。

```javascript
export default {
  async scheduled(event, env) {
    const now = Date.now();
    const TWO_YEARS = 1000 * 60 * 60 * 24 * 365 * 2;

    let cursor = undefined;

    do {
      const list = await env.ACCESS_LOG.list({ cursor });
      cursor = list.cursor;

      for (const item of list.keys) {
        const lastAccess = Number(await env.ACCESS_LOG.get(item.name));
        if (!lastAccess) continue;

        if (now - lastAccess > TWO_YEARS) {
          // R2 から削除
          await env.MY_BUCKET.delete(item.name);

          // KV からも削除
          await env.ACCESS_LOG.delete(item.name);
        }
      }
    } while (cursor);
  }
};
```

---

# 5. この方式があなたの要件に最適な理由

### ✔ 内容ハッシュ＝ファイル名を壊さない  
prefix を付けないため、  
**同じ内容は必ず同じファイル名になる**という設計が守られる。

### ✔ 60,000オブジェクトでも安全に処理できる  
KV.list() のページングで  
**60回ループするだけで全キーを処理可能**。

Workers の CPU 時間にも十分収まる。

### ✔ コストはほぼゼロ  
- Workers：無料枠で十分  
- KV：60,000キーでもほぼ無料  
- R2：10GB無料、追加10GB ≈ 20円/月

### ✔ シンプルで壊れにくい  
prefix 分割や複雑な管理が不要。  
Cloudflare の標準機能だけで完結。

---

# 6. 運用のポイント

- **必ず Workers 経由で R2 を読み込む**  
  → 最終アクセス日時が記録される  
- **Cron は毎日実行で十分**  
  → 60,000件でも余裕  
- **ハッシュ名は SHA-256 推奨**  
  → 衝突がほぼ起きない

---

# 7. まとめ

あなたの要件（内容ハッシュ名、60,000オブジェクト、2年アクセスなし自動削除）には  
**KV.list() ページング方式が最もシンプルで安全で高速**です。

- prefix 分割は不要  
- ハッシュ名を壊さない  
- Workers + KV + R2 の標準機能だけで完結  
- コストはほぼ無料
